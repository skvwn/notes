# Бесплатный инференс open-source ИИ для Android
[Gonka API](gonka-api.org) предоставляет новым пользователям 10 миллионов токенов бесплатно при регистрации. При использовании лаконичного системного промпта средний чат может потребовать около 10 000 токенов, что позволяет выполнить до 1 000 запросов на одну учетную запись. Приложение для Android [Chatbox](https://play.google.com/store/apps/details?id=xyz.chatboxapp.chatbox) обеспечивает полный контроль над системным промптом, который по умолчанию содержит стандартное сообщение *You're helpful assistant*.

## Установка
1. Получите API-ключ, зарегистрировавшись на [Gonka API](gonka-api.org).
2. Установите [Chatbox](https://play.google.com/store/apps/details?id=xyz.chatboxapp.chatbox).
3. Перейдите в раздел *Chatbox* -> *Settings* -> *Model Provider* -> *OpenAI*.
4. Введите ваш API-ключ в соответствующее поле и укажите в качестве API Host адрес https://hskyauefqcgbvgvxkluj.supabase.co/functions/v1/gonka.
5. Нажмите *Fetch*.
6. Удалите (кнопкой *-* справа от названия) все модели семьи ChatGPT.
7. Добавьте актуальные модели сети [Gonka AI](https://gonka-api.org/dashboard) (кнопкой *+* справа от названия).
